## The idea

Move two pointers through a sequence at different speeds, usually `slow` by one step and `fast` by two. This simple trick, also called **Floyd's tortoise and hare**, answers two common questions without any extra memory:

- **Is there a cycle?** If there is, `fast` laps `slow` and they eventually meet. If not, `fast` reaches the end.
- **Where's the middle?** When `fast` reaches the end, `slow` has covered exactly half the distance.

## When to use it

- Linked list problems where you can't index into the middle.
- Detecting a **cycle** in a linked list, or in any sequence where each value points to the next (like Happy Number or Find the Duplicate Number).
- You're asked to do it in `O(1)` extra space, ruling out a hash set of visited nodes.

## Problem 1: Linked List Cycle

<Problem difficulty="Easy" link="https://leetcode.com/problems/linked-list-cycle/">

Given the `head` of a linked list, return `True` if the list has a cycle, meaning some node's `next` pointer leads back to an earlier node.

</Problem>

### Approach

A hash set of visited nodes works, but uses `O(n)` space. With two pointers: once both are inside the cycle, `fast` gains one node on `slow` with each step, so the gap between them shrinks by one each time until they're at the same node. They can't skip past each other.

<Visualizer id="linked-list-cycle" />

<CodeTabs>

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def has_cycle(head: ListNode | None) -> bool:
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:
            return True
    return False
```

```java
class ListNode {
    int val;
    ListNode next;
    ListNode(int val) { this.val = val; }
}

public boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;
    }
    return false;
}
```

```cpp
struct ListNode {
    int val;
    ListNode* next;
    ListNode(int v) : val(v), next(nullptr) {}
};

bool hasCycle(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return true;
    }
    return false;
}
```

```javascript
class ListNode {
  constructor(val = 0, next = null) {
    this.val = val;
    this.next = next;
  }
}

function hasCycle(head) {
  let slow = head;
  let fast = head;
  while (fast && fast.next) {
    slow = slow.next;
    fast = fast.next.next;
    if (slow === fast) return true;
  }
  return false;
}
```

</CodeTabs>

<Complexity time="O(n)" space="O(1)" />

## Problem 2: Middle of the Linked List

<Problem difficulty="Easy" link="https://leetcode.com/problems/middle-of-the-linked-list/">

Given the `head` of a singly linked list, return its middle node. If there are two middle nodes, return the second one.

**Example:** `[1, 2, 3, 4, 5]` returns the node with value `3`.

</Problem>

`fast` moves twice as fast as `slow`, so when `fast` can't move any further, `slow` is halfway.

<Visualizer id="middle-of-list" />

<CodeTabs>

```python
def middle_node(head: ListNode) -> ListNode:
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    return slow
```

```java
public ListNode middleNode(ListNode head) {
    ListNode slow = head, fast = head;

        slow = slow.next;
        fast = fast.next.next;
    }
    return slow;
}
```

```

function middleNode(head) {

    slow = slow.next;
    fast = fast.next.next;
  }

```

<Complexity time="O(n)" space="O(1)" />

<Callout type="interview">
Finding the middle is often a **building block** rather than the whole problem. Palindrome Linked List, Reorder List and Sort List all start by finding the middle with fast and slow pointers, then reverse or merge the halves.
</Callout>
