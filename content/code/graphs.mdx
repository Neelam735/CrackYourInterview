## The idea

A graph is a set of **nodes** connected by **edges**. Trees and linked lists are special graphs, but in general a graph can have cycles, disconnected pieces, and edges that point one way (directed) or both ways (undirected).

The hardest part of a graph problem is often noticing that it *is* a graph problem. Grids, course prerequisites, word ladders, flight routes and friend networks are all graphs in disguise.

### Representing a graph

Interviews usually give you an **edge list** like `[[0, 1], [1, 2]]`. Convert it to an **adjacency list**, mapping each node to its neighbours, before you start:

```python
graph = defaultdict(list)
for a, b in edges:
    graph[a].append(b)
    graph[b].append(a)  # omit for a directed graph
```

A grid is already a graph: each cell is a node, and its neighbours are the cells up, down, left and right.

### Traversal

Both BFS and DFS visit every reachable node in `O(V + E)` time. The one rule that matters: **track visited nodes**, or a cycle will loop forever.

| | BFS | DFS |
|-|-----|-----|
| Data structure | Queue | Stack or recursion |
| Visits nodes | In order of distance from the start | One branch at a time |
| Best for | Shortest path in an unweighted graph | Connectivity, cycles, exploring all paths |

## When to use it

- A grid where you count or measure regions: **islands, rooms, flood fill**.
- Dependencies or ordering: **prerequisites, build order** (topological sort).
- Shortest number of steps: **word ladder, knight moves** (BFS).
- Connectivity: **number of provinces, is the graph a valid tree?**

## Problem 1: Number of Islands

<Problem difficulty="Medium" link="https://leetcode.com/problems/number-of-islands/">

Given an `m × n` grid of `"1"` (land) and `"0"` (water), return the number of islands. An island is a group of land cells connected horizontally or vertically.

</Problem>

Scan every cell. When you find land you haven't visited, you've found a new island: count it, then **flood-fill** it with BFS or DFS, marking every connected land cell as visited so it isn't counted again.

<Visualizer id="number-of-islands" />

<CodeTabs>

```python
from collections import deque

def num_islands(grid: list[list[str]]) -> int:
    rows, cols = len(grid), len(grid[0])
    visited = set()

    def bfs(r, c):
        queue = deque([(r, c)])
        visited.add((r, c))
        while queue:
            cr, cc = queue.popleft()
            for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                nr, nc = cr + dr, cc + dc
                if (0 <= nr < rows and 0 <= nc < cols
                        and grid[nr][nc] == "1" and (nr, nc) not in visited):
                    visited.add((nr, nc))
                    queue.append((nr, nc))

    islands = 0
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == "1" and (r, c) not in visited:
                islands += 1
                bfs(r, c)
    return islands
```

```java
public int numIslands(char[][] grid) {
    int rows = grid.length, cols = grid[0].length;
    boolean[][] visited = new boolean[rows][cols];
    int[][] dirs = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
    int islands = 0;
    for (int r = 0; r < rows; r++) {
        for (int c = 0; c < cols; c++) {
            if (grid[r][c] != '1' || visited[r][c]) continue;
            islands++;
            Deque<int[]> queue = new ArrayDeque<>();
            queue.offer(new int[] {r, c});
            visited[r][c] = true;
            while (!queue.isEmpty()) {
                int[] cell = queue.poll();
                for (int[] d : dirs) {
                    int nr = cell[0] + d[0], nc = cell[1] + d[1];
                    if (nr >= 0 && nr < rows && nc >= 0 && nc < cols
                            && grid[nr][nc] == '1' && !visited[nr][nc]) {
                        visited[nr][nc] = true;
                        queue.offer(new int[] {nr, nc});
                    }
                }
            }
        }
    }
    return islands;
}
```

```javascript
function numIslands(grid) {
  const rows = grid.length;
  const cols = grid[0].length;
  const visited = grid.map((row) => row.map(() => false));
  const dirs = [[1, 0], [-1, 0], [0, 1], [0, -1]];
  let islands = 0;
  for (let r = 0; r < rows; r++) {
    for (let c = 0; c < cols; c++) {
      if (grid[r][c] !== "1" || visited[r][c]) continue;
      islands++;
      const queue = [[r, c]];
      visited[r][c] = true;
      for (let head = 0; head < queue.length; head++) {
        const [cr, cc] = queue[head];
        for (const [dr, dc] of dirs) {
          const nr = cr + dr;
          const nc = cc + dc;
          if (nr >= 0 && nr < rows && nc >= 0 && nc < cols &&
              grid[nr][nc] === "1" && !visited[nr][nc]) {
            visited[nr][nc] = true;
            queue.push([nr, nc]);
          }
        }
      }
    }
  }
  return islands;
}
```

<Callout type="tip">
Mark a cell visited **when you enqueue it**, not when you dequeue it. Otherwise the same cell can be added to the queue several times by different neighbours.
</Callout>

## Problem 2: Course Schedule

<Problem difficulty="Medium" link="https://leetcode.com/problems/course-schedule/">

There are `numCourses` courses labelled `0` to `numCourses - 1`. `prerequisites[i] = [a, b]` means you must take course `b` before course `a`. Return `True` if you can finish every course.

</Problem>

### Topological sort (Kahn's algorithm)

Draw an edge `b → a` for each prerequisite. You can finish every course exactly when this directed graph has **no cycle**.

Count each course's **in-degree**: how many prerequisites it still needs. Courses with in-degree 0 can be taken now, so put them in a queue. Each time you take a course, every course that depended on it loses one prerequisite; any that drop to 0 join the queue. If you take all the courses, there was no cycle.

<Visualizer id="course-schedule" />

<CodeTabs>

```python
from collections import deque

def can_finish(num_courses: int, prerequisites: list[list[int]]) -> bool:
    graph = [[] for _ in range(num_courses)]
    indegree = [0] * num_courses
    for course, pre in prerequisites:
        graph[pre].append(course)
        indegree[course] += 1

    queue = deque(i for i in range(num_courses) if indegree[i] == 0)
    taken = 0
    while queue:
        course = queue.popleft()
        taken += 1
        for nxt in graph[course]:
            indegree[nxt] -= 1
            if indegree[nxt] == 0:
                queue.append(nxt)
    return taken == num_courses
```

```java
public boolean canFinish(int numCourses, int[][] prerequisites) {
    List<List<Integer>> graph = new ArrayList<>();
    for (int i = 0; i < numCourses; i++) graph.add(new ArrayList<>());
    int[] indegree = new int[numCourses];
    for (int[] p : prerequisites) {
        graph.get(p[1]).add(p[0]);
        indegree[p[0]]++;
    }

    Deque<Integer> queue = new ArrayDeque<>();
    for (int i = 0; i < numCourses; i++) if (indegree[i] == 0) queue.offer(i);
    int taken = 0;
    while (!queue.isEmpty()) {
        int course = queue.poll();
        taken++;
        for (int next : graph.get(course)) {
            if (--indegree[next] == 0) queue.offer(next);
        }
    }
    return taken == numCourses;
}
```

```cpp
bool canFinish(int numCourses, const vector<vector<int>>& prerequisites) {
    vector<vector<int>> graph(numCourses);
    vector<int> indegree(numCourses, 0);
    for (const auto& p : prerequisites) {
        graph[p[1]].push_back(p[0]);
        indegree[p[0]]++;
    }

    queue<int> q;
    for (int i = 0; i < numCourses; i++) if (indegree[i] == 0) q.push(i);
    int taken = 0;
    while (!q.empty()) {
        int course = q.front();
        q.pop();
        taken++;
        for (int next : graph[course]) {
            if (--indegree[next] == 0) q.push(next);
        }
    }
    return taken == numCourses;
}
```

```javascript
function canFinish(numCourses, prerequisites) {
  const graph = Array.from({ length: numCourses }, () => []);
  const indegree = new Array(numCourses).fill(0);
  for (const [course, pre] of prerequisites) {
    graph[pre].push(course);
    indegree[course]++;
  }

  const queue = [];
  for (let i = 0; i < numCourses; i++) if (indegree[i] === 0) queue.push(i);
  let taken = 0;
  for (let head = 0; head < queue.length; head++) {
    taken++;
    for (const next of graph[queue[head]]) {
      if (--indegree[next] === 0) queue.push(next);
    }
  }
  return taken === numCourses;
}
```
