## The idea

A heap is a binary tree where every parent is smaller than its children (a **min-heap**) or larger (a **max-heap**). That one rule keeps the smallest (or largest) item at the root at all times.

| Operation | Cost |
|-----------|------|
| Look at the top | `O(1)` |
| Push | `O(log n)` |
| Pop the top | `O(log n)` |
| Build from a list (heapify) | `O(n)` |

Heaps are stored as plain arrays: the children of index `i` are at `2i + 1` and `2i + 2`. When you push, the new item **sifts up** past larger parents. When you pop, the last item moves to the root and **sifts down**.

## When to use it

- **Top k / kth largest / kth smallest.** Keep a heap of size `k` instead of sorting everything: `O(n log k)` instead of `O(n log n)`.
- You repeatedly need the **current minimum or maximum** while items keep arriving: scheduling, streaming medians.
- **Merging sorted sequences**: keep one candidate from each sequence in the heap.
- **Shortest paths** in weighted graphs (Dijkstra's algorithm).

### The size-k trick

To keep the `k` **largest** items, use a **min**-heap of size `k`. Whenever it grows past `k`, pop the smallest, which can't be among the `k` largest. At the end the heap holds the `k` largest items, and its root is the `k`th largest. (Flip everything for the `k` smallest.)

## Heaps in each language

| Language | Min-heap | Max-heap |
|----------|----------|----------|
| Python | `heapq` on a list | push negated values |
| Java | `new PriorityQueue<>()` | `new PriorityQueue<>(Collections.reverseOrder())` |
| C++ | `priority_queue<int, vector<int>, greater<int>>` | `priority_queue<int>` (the default) |
| JavaScript | no built-in: use the class below | same class, reversed comparator |

```javascript nocheck title="heap.js"
class Heap {
  // compare(a, b) < 0 means a belongs closer to the top.
  constructor(compare = (a, b) => a - b) {
    this.items = [];
    this.compare = compare;
  }

  get size() {
    return this.items.length;
  }

  peek() {
    return this.items[0];
  }

  push(value) {
    const items = this.items;
    items.push(value);
    let i = items.length - 1;
    while (i > 0) {
      const parent = (i - 1) >> 1;
      if (this.compare(items[parent], items[i]) <= 0) break;
      [items[parent], items[i]] = [items[i], items[parent]];
      i = parent;
    }
  }

  pop() {
    const items = this.items;
    const top = items[0];
    const last = items.pop();
    if (items.length > 0) {
      items[0] = last;
      let i = 0;
      for (;;) {
        const left = 2 * i + 1;
        const right = left + 1;
        let best = i;
        if (left < items.length && this.compare(items[left], items[best]) < 0) best = left;
        if (right < items.length && this.compare(items[right], items[best]) < 0) best = right;
        if (best === i) break;
        [items[best], items[i]] = [items[i], items[best]];
        i = best;
      }
    }
    return top;
  }
}
```

The JavaScript solutions in this course use this `Heap` class.

<Callout type="warning">
C++'s `priority_queue` is a **max**-heap by default, while Python's `heapq` and Java's `PriorityQueue` are **min**-heaps. Mixing them up is a classic interview bug.
</Callout>
