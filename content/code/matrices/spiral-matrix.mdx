<Problem difficulty="Medium" link="https://leetcode.com/problems/spiral-matrix/">

Given an `m × n` matrix, return all its elements in **spiral order**: across the top row, down the right column, back along the bottom row, up the left column, then inward.

**Example:** `[[1, 2, 3], [4, 5, 6], [7, 8, 9]]` returns `[1, 2, 3, 6, 9, 8, 7, 4, 5]`.

</Problem>

## Approach

Matrix questions in interviews are mostly about **careful index handling**. Here, keep four boundaries for the part of the matrix not yet visited: `top`, `bottom`, `left`, `right`.

Repeat while `top <= bottom` and `left <= right`:

1. Walk the **top row** from `left` to `right`, then move `top` down.
2. Walk the **right column** from `top` to `bottom`, then move `right` left.
3. If rows remain, walk the **bottom row** from `right` to `left`, then move `bottom` up.
4. If columns remain, walk the **left column** from `bottom` to `top`, then move `left` right.

The checks in steps 3 and 4 matter for non-square matrices: after steps 1 and 2, the remaining part might be a single row or column, and walking it back the other way would repeat elements.

## Solution

<CodeTabs>

```python
def spiral_order(matrix: list[list[int]]) -> list[int]:
    result = []
    top, bottom, left, right = 0, len(matrix) - 1, 0, len(matrix[0]) - 1
    while top <= bottom and left <= right:
        for c in range(left, right + 1):            # top row, left to right
            result.append(matrix[top][c])
        top += 1
        for r in range(top, bottom + 1):            # right column, downward
            result.append(matrix[r][right])
        right -= 1
        if top <= bottom:
            for c in range(right, left - 1, -1):    # bottom row, right to left
                result.append(matrix[bottom][c])
            bottom -= 1
        if left <= right:
            for r in range(bottom, top - 1, -1):    # left column, upward
                result.append(matrix[r][left])
            left += 1
    return result
```

```java
public List<Integer> spiralOrder(int[][] matrix) {
    List<Integer> result = new ArrayList<>();
    int top = 0, bottom = matrix.length - 1, left = 0, right = matrix[0].length - 1;
    while (top <= bottom && left <= right) {
        for (int c = left; c <= right; c++) result.add(matrix[top][c]);   // top row
        top++;
        for (int r = top; r <= bottom; r++) result.add(matrix[r][right]); // right column
        right--;
        if (top <= bottom) {
            for (int c = right; c >= left; c--) result.add(matrix[bottom][c]);  // bottom row
            bottom--;
        }
        if (left <= right) {
            for (int r = bottom; r >= top; r--) result.add(matrix[r][left]);    // left column
            left++;
        }
    }
    return result;
}
```
