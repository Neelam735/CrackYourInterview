<Problem difficulty="Medium" link="https://leetcode.com/problems/set-matrix-zeroes/">

Given an `m × n` integer matrix, if an element is `0`, set its **entire row and column** to `0`. Do it in place.

**Example:** `[[1, 1, 1], [1, 0, 1], [1, 1, 1]]` becomes `[[1, 0, 1], [0, 0, 0], [1, 0, 1]]`.

</Problem>

## The trap

Zeroing rows and columns **as you find zeros** creates new zeros that the scan then mistakes for original ones, wiping out the whole matrix. You have to **record** which rows and columns to clear first, then clear them.

## Approach

The simple fix is two sets, one of rows and one of columns, using `O(m + n)` space. To use `O(1)` space, store those markers **inside the matrix**:

- `matrix[r][0] = 0` marks "clear row `r`".
- `matrix[0][c] = 0` marks "clear column `c`".

The first row and column are both used as markers **and** hold real data, so first remember whether they themselves contained a zero, in two booleans. Then:

1. Record whether the first row and first column have zeros.
2. For every other cell that's `0`, mark its row and column in the first column and row.
3. Clear every other cell whose row or column is marked.
4. Finally, clear the first row and/or column if step 1 said so.

## Solution

<CodeTabs>

```python
def set_zeroes(matrix: list[list[int]]) -> None:
    rows, cols = len(matrix), len(matrix[0])
    first_row_zero = any(matrix[0][c] == 0 for c in range(cols))
    first_col_zero = any(matrix[r][0] == 0 for r in range(rows))

    for r in range(1, rows):                    # mark rows and columns to clear
        for c in range(1, cols):
            if matrix[r][c] == 0:
                matrix[r][0] = matrix[0][c] = 0
    for r in range(1, rows):                    # clear using the markers
        for c in range(1, cols):
            if matrix[r][0] == 0 or matrix[0][c] == 0:
                matrix[r][c] = 0
    if first_row_zero:
        for c in range(cols):
            matrix[0][c] = 0
    if first_col_zero:
        for r in range(rows):
            matrix[r][0] = 0
```

```java
public void setZeroes(int[][] matrix) {
    int rows = matrix.length, cols = matrix[0].length;
    boolean firstRowZero = false, firstColZero = false;
    for (int c = 0; c < cols; c++) if (matrix[0][c] == 0) firstRowZero = true;
    for (int r = 0; r < rows; r++) if (matrix[r][0] == 0) firstColZero = true;

    for (int r = 1; r < rows; r++)  // mark rows and columns to clear
        for (int c = 1; c < cols; c++)
            if (matrix[r][c] == 0) matrix[r][0] = matrix[0][c] = 0;
    for (int r = 1; r < rows; r++)  // clear using the markers
        for (int c = 1; c < cols; c++)
            if (matrix[r][0] == 0 || matrix[0][c] == 0) matrix[r][c] = 0;
    if (firstRowZero) for (int c = 0; c < cols; c++) matrix[0][c] = 0;
    if (firstColZero) for (int r = 0; r < rows; r++) matrix[r][0] = 0;
}
```

```javascript
function setZeroes(matrix) {
  const rows = matrix.length;
  const cols = matrix[0].length;
  const firstRowZero = matrix[0].some((v) => v === 0);
  const firstColZero = matrix.some((row) => row[0] === 0);

  for (let r = 1; r < rows; r++) // mark rows and columns to clear
    for (let c = 1; c < cols; c++)
      if (matrix[r][c] === 0) matrix[r][0] = matrix[0][c] = 0;
  for (let r = 1; r < rows; r++) // clear using the markers
    for (let c = 1; c < cols; c++)
      if (matrix[r][0] === 0 || matrix[0][c] === 0) matrix[r][c] = 0;
  if (firstRowZero) matrix[0].fill(0);
  if (firstColZero) for (const row of matrix) row[0] = 0;
}
```
