<Problem difficulty="Hard" link="https://leetcode.com/problems/employee-free-time/">

You're given `schedule`, a list of employees, where each employee's working hours are a sorted list of non-overlapping intervals. Return the list of **finite** intervals during which **every** employee is free, sorted by start time. Ignore the open-ended free time before the first meeting and after the last one, and leave out zero-length gaps.

**Example:** `schedule = [[[1, 2], [5, 6]], [[1, 3]], [[4, 10]]]` returns `[[3, 4]]`.

</Problem>

## Reframe

Time is free for everyone exactly when **no one** is busy. So it doesn't matter whose interval is whose. Pour all the busy intervals into one list, and the answer is the set of **gaps** in their union.

## Approach

1. Flatten every employee's intervals into one list and **sort by start**.
2. Sweep through, tracking `end`, the latest end time seen so far:
   - If the next interval starts **after** `end`, there's a gap `[end, start]` where everyone is free. Record it.
   - Either way, extend `end = max(end, interval end)`.

This is [Merge Intervals](/learn/code/intervals/merge-intervals) where we keep the gaps instead of the merged blocks.

## Solution

<CodeTabs>

```python
def employee_free_time(schedule: list[list[list[int]]]) -> list[list[int]]:
    busy = sorted((iv for employee in schedule for iv in employee), key=lambda x: x[0])
    free = []
    end = busy[0][1]
    for s, e in busy[1:]:
        if s > end:                 # nobody is working between end and s
            free.append([end, s])
        end = max(end, e)
    return free
```

```java
public List<int[]> employeeFreeTime(List<List<int[]>> schedule) {
    List<int[]> busy = new ArrayList<>();
    for (List<int[]> employee : schedule) busy.addAll(employee);
    busy.sort((a, b) -> Integer.compare(a[0], b[0]));
    List<int[]> free = new ArrayList<>();
    int end = busy.get(0)[1];
    for (int[] iv : busy) {
        if (iv[0] > end) free.add(new int[] {end, iv[0]});  // nobody is working in between
        end = Math.max(end, iv[1]);
    }
    return free;
}
```

```cpp
vector<vector<int>> employeeFreeTime(const vector<vector<vector<int>>>& schedule) {
    vector<vector<int>> busy;
    for (const auto& employee : schedule) busy.insert(busy.end(), employee.begin(), employee.end());
    sort(busy.begin(), busy.end());
    vector<vector<int>> free;
    int end = busy[0][1];
    for (const auto& iv : busy) {
        if (iv[0] > end) free.push_back({end, iv[0]});  // nobody is working in between
        end = max(end, iv[1]);
    }
    return free;
}
```

```javascript
function employeeFreeTime(schedule) {
  const busy = schedule.flat().sort((a, b) => a[0] - b[0]);
  const free = [];
  let end = busy[0][1];
  for (const [s, e] of busy) {
    if (s > end) free.push([end, s]); // nobody is working in between
    end = Math.max(end, e);
  }
  return free;
}
```

<Complexity time="O(N log N), N = total intervals" space="O(N)" />

<Callout type="tip" title="Using the fact that each list is sorted">
Each employee's list is already sorted, so you can merge them like [Merge K Sorted Lists](/learn/code/heap/merge-k-sorted-lists) with a min-heap holding one interval per employee. That brings the time down to `O(N log k)` for `k` employees. Mention it as a follow-up; the sort-everything version is simpler to write.
</Callout>
