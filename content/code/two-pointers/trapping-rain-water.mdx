<Problem difficulty="Hard" link="https://leetcode.com/problems/trapping-rain-water/">

Given `n` non-negative integers representing an elevation map where each bar has width 1, compute how much water it can trap after raining.

**Example:** `height = [0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1]` returns `6`.

</Problem>

## Key observation

The water above bar `i` is decided by the tallest wall on its left and the tallest wall on its right:

```text nocheck
water[i] = min(maxLeft[i], maxRight[i]) - height[i]
```

A simple solution precomputes `maxLeft` and `maxRight` arrays in two passes, which takes `O(n)` time and `O(n)` space.

## Two pointers

You don't actually need both arrays. Keep a pointer at each end and the tallest wall seen so far from each side: `left_max` and `right_max`.

If `left_max < right_max`, then for the bar at `left`:

- its left wall is exactly `left_max`, and
- its right wall is **at least** `right_max`, which is already taller.

So the shorter wall, `left_max`, decides the water at `left`. Add `left_max - height[left]` and move `left` forward. Otherwise do the same thing from the right side.

In other words, **always process the side with the lower wall**, because that side's water level is already known.

## Solution

<CodeTabs>

```python
def trap(height: list[int]) -> int:
    left, right = 0, len(height) - 1
    left_max = right_max = 0
    water = 0
    while left < right:
        left_max = max(left_max, height[left])
        right_max = max(right_max, height[right])
        if left_max < right_max:
            water += left_max - height[left]    # left wall decides
            left += 1
        else:
            water += right_max - height[right]  # right wall decides
            right -= 1
    return water
```

```java
public int trap(int[] height) {
    int left = 0, right = height.length - 1;
    int leftMax = 0, rightMax = 0, water = 0;
    while (left < right) {
        leftMax = Math.max(leftMax, height[left]);
        rightMax = Math.max(rightMax, height[right]);
        if (leftMax < rightMax) {
            water += leftMax - height[left];    // left wall decides
            left++;
        } else {
            water += rightMax - height[right];  // right wall decides
            right--;
        }
    }
    return water;
}
```
