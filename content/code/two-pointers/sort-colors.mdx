<Problem difficulty="Medium" link="https://leetcode.com/problems/sort-colors/">

Given an array `nums` containing only `0`, `1` and `2` (red, white and blue), sort it **in place** so equal numbers are next to each other in the order 0, 1, 2. Don't use a library sort.

**Example:** `nums = [2, 0, 2, 1, 1, 0]` becomes `[0, 0, 1, 1, 2, 2]`.

</Problem>

## Approach

You could count the 0s, 1s and 2s and rewrite the array, but that takes two passes. The **Dutch national flag** algorithm does it in one, using three pointers that split the array into four regions:

| Range | Contents |
|-------|----------|
| `[0, low)` | 0s |
| `[low, mid)` | 1s |
| `[mid, high]` | not yet looked at |
| `(high, n - 1]` | 2s |

Look at `nums[mid]`:

- **0:** swap it to the end of the 0s region (`low`), then advance both `low` and `mid`.
- **1:** it's already in the right region, so advance `mid`.
- **2:** swap it to the front of the 2s region (`high`) and move `high` back. **Don't** advance `mid`: the value you just swapped in hasn't been checked yet.

Stop when `mid` passes `high`, since there's nothing left to look at.

## Solution

<CodeTabs>

```python
def sort_colors(nums: list[int]) -> None:
    low, mid, high = 0, 0, len(nums) - 1
    while mid <= high:
        if nums[mid] == 0:
            nums[low], nums[mid] = nums[mid], nums[low]
            low += 1
            mid += 1
        elif nums[mid] == 1:
            mid += 1
        else:
            nums[mid], nums[high] = nums[high], nums[mid]
            high -= 1   # don't advance mid: the swapped-in value is unchecked
```

```java
public void sortColors(int[] nums) {
    int low = 0, mid = 0, high = nums.length - 1;
    while (mid <= high) {
        if (nums[mid] == 0) {
            swap(nums, low++, mid++);
        } else if (nums[mid] == 1) {
            mid++;
        } else {
            swap(nums, mid, high--);  // don't advance mid: the swapped-in value is unchecked
        }
    }
}

private void swap(int[] nums, int i, int j) {
    int tmp = nums[i];
    nums[i] = nums[j];
    nums[j] = tmp;
}
```

```cpp
void sortColors(vector<int>& nums) {
    int low = 0, mid = 0, high = (int)nums.size() - 1;
    while (mid <= high) {
        if (nums[mid] == 0) {
            swap(nums[low++], nums[mid++]);
        } else if (nums[mid] == 1) {
            mid++;
        } else {
            swap(nums[mid], nums[high--]);  // don't advance mid: the swapped-in value is unchecked
        }
    }
}
```

```javascript
function sortColors(nums) {
  let low = 0;
  let mid = 0;
  let high = nums.length - 1;
  while (mid <= high) {
    if (nums[mid] === 0) {
      [nums[low], nums[mid]] = [nums[mid], nums[low]];
      low++;
      mid++;
    } else if (nums[mid] === 1) {
      mid++;
    } else {
      [nums[mid], nums[high]] = [nums[high], nums[mid]];
      high--; // don't advance mid: the swapped-in value is unchecked
    }
  }
}
```

<Complexity time="O(n)" space="O(1)" />

<Callout type="warning">
The most common bug is advancing `mid` after swapping with `high`. The value that came from `high` could be a 0 or a 2, so it still needs to be checked.
</Callout>
