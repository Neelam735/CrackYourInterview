<Problem difficulty="Hard" link="https://leetcode.com/problems/largest-rectangle-in-histogram/">

Given an array `heights` of bar heights in a histogram where every bar has width 1, return the area of the largest rectangle that fits inside the histogram.

**Example:** `heights = [2, 1, 5, 6, 2, 3]` returns `10`: the bars of height 5 and 6 together hold a rectangle of height 5 and width 2.

</Problem>

## Key observation

The best rectangle is as tall as **some bar** in it. So for every bar `i`, ask: if the rectangle has exactly this bar's height, how wide can it be? It stretches left and right until it hits a **shorter** bar on each side:

```text nocheck
area(i) = heights[i] × (right_limit - left_limit - 1)
```

where `left_limit` and `right_limit` are the nearest shorter bars on each side. That's a "previous smaller" and "next smaller" question, which a [monotonic stack](/learn/code/stack/monotonic-stack) answers in one pass.

## Approach

Keep a stack of indices with **increasing** heights.

When bar `i` is shorter than the bar on top of the stack, the top bar can't extend past `i`, so its rectangle is now complete:

- Pop it. Its height is `heights[top]`.
- Its **right limit** is `i` (the shorter bar that stopped it).
- Its **left limit** is the new top of the stack, the nearest earlier bar that is shorter. If the stack is empty, it reaches all the way to the start, so the left limit is `-1`.
- Width = `i - left - 1`.

To flush the bars still on the stack at the end, process one extra bar of height `0` after the last real bar. It's shorter than everything, so it pops them all.

## Solution

<CodeTabs>

```python
def largest_rectangle_area(heights: list[int]) -> int:
    stack = []  # indices, heights increasing
    best = 0
    for i in range(len(heights) + 1):
        h = heights[i] if i < len(heights) else 0   # sentinel bar flushes the stack
        while stack and heights[stack[-1]] > h:
            height = heights[stack.pop()]
            left = stack[-1] if stack else -1        # nearest shorter bar on the left
            best = max(best, height * (i - left - 1))
        stack.append(i)
    return best
```

```java
public int largestRectangleArea(int[] heights) {
    Deque<Integer> stack = new ArrayDeque<>();  // indices, heights increasing
    int best = 0, n = heights.length;
    for (int i = 0; i <= n; i++) {
        int h = i < n ? heights[i] : 0;  // sentinel bar flushes the stack
        while (!stack.isEmpty() && heights[stack.peek()] > h) {
            int height = heights[stack.pop()];
            int left = stack.isEmpty() ? -1 : stack.peek();  // nearest shorter bar on the left
            best = Math.max(best, height * (i - left - 1));
        }
        stack.push(i);
    }
    return best;
}
```

```javascript
function largestRectangleArea(heights) {
  const stack = []; // indices, heights increasing
  let best = 0;
  const n = heights.length;
  for (let i = 0; i <= n; i++) {
    const h = i < n ? heights[i] : 0; // sentinel bar flushes the stack
    while (stack.length && heights[stack[stack.length - 1]] > h) {
      const height = heights[stack.pop()];
      const left = stack.length ? stack[stack.length - 1] : -1; // nearest shorter bar on the left
      best = Math.max(best, height * (i - left - 1));
    }
    stack.push(i);
  }
  return best;
}
```
