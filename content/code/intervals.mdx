## The idea

Interval problems give you ranges like `[start, end]`: meetings, bookings, time ranges. Comparing every pair to see which ones overlap takes `O(n²)` time.

The trick is to **sort first**. Once intervals are sorted by start time, any interval that overlaps the current one must come right after it. A single left-to-right sweep is then enough, so the whole solution costs `O(n log n)` for the sort.

Two intervals `[a, b]` and `[c, d]` with `a ≤ c` overlap exactly when `c ≤ b`: the second one starts before the first one ends.

## When to use it

- The input is a list of ranges, meetings or time slots.
- You need to **merge** overlapping ranges, **insert** a new one, or find **gaps**.
- You need the **minimum number of rooms**, or the **maximum number of non-overlapping** intervals.

| Goal | Sort by | Why |
|------|---------|-----|
| Merge or insert | Start | Overlapping intervals become neighbours |
| Keep as many non-overlapping intervals as possible | End | Finishing early leaves the most room for the rest |

## Problem 1: Merge Intervals

<Problem difficulty="Medium" link="https://leetcode.com/problems/merge-intervals/">

Given an array of `intervals` where `intervals[i] = [start, end]`, merge all overlapping intervals and return the non-overlapping intervals that cover the same ranges.

**Example:** `[[1,3],[2,6],[8,10],[9,12],[15,18]]` returns `[[1,6],[8,12],[15,18]]`.

</Problem>

Sort by start. Then for each interval, compare it with the **last merged interval**:

- It starts **after** the last one ends: there's a gap, so start a new group.
- Otherwise they overlap: extend the last one's end to cover both.

<Visualizer id="merge-intervals" />

<CodeTabs>

```python
def merge(intervals: list[list[int]]) -> list[list[int]]:
    intervals.sort(key=lambda x: x[0])
    merged = []
    for start, end in intervals:
        if not merged or merged[-1][1] < start:
            merged.append([start, end])              # gap: new group
        else:
            merged[-1][1] = max(merged[-1][1], end)  # overlap: extend
    return merged
```

```java
public int[][] merge(int[][] intervals) {
    Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));
    List<int[]> merged = new ArrayList<>();
    for (int[] cur : intervals) {
        if (merged.isEmpty() || merged.get(merged.size() - 1)[1] < cur[0]) {
            merged.add(new int[] {cur[0], cur[1]});  // gap: new group
        } else {
            int[] last = merged.get(merged.size() - 1);
            last[1] = Math.max(last[1], cur[1]);     // overlap: extend
        }
    }
    return merged.toArray(new int[0][]);
}
```

```cpp
vector<vector<int>> merge(vector<vector<int>> intervals) {
    sort(intervals.begin(), intervals.end());
    vector<vector<int>> merged;
    for (const auto& cur : intervals) {
        if (merged.empty() || merged.back()[1] < cur[0]) {
            merged.push_back(cur);                             // gap: new group
        } else {
            merged.back()[1] = max(merged.back()[1], cur[1]);  // overlap: extend
        }
    }
    return merged;
}
```

```javascript
function merge(intervals) {
  intervals.sort((a, b) => a[0] - b[0]);
  const merged = [];
  for (const [start, end] of intervals) {
    const last = merged[merged.length - 1];
    if (!last || last[1] < start) merged.push([start, end]); // gap: new group
    else last[1] = Math.max(last[1], end);                    // overlap: extend
  }
  return merged;
}
```

</CodeTabs>

<Complexity time="O(n log n)" space="O(n) for the output" />

<Callout type="warning">
Use `max(last_end, end)`, not just `end`. An interval can sit entirely inside the previous one, like `[1, 10]` followed by `[2, 3]`, and then the merged end must stay at 10.
</Callout>

## Problem 2: Non-overlapping Intervals

<Problem difficulty="Medium" link="https://leetcode.com/problems/non-overlapping-intervals/">

Given an array of `intervals`, return the minimum number of intervals you need to remove so the rest don't overlap. Intervals that only touch, like `[1, 2]` and `[2, 3]`, don't overlap.

**Example:** `[[1,2],[2,3],[3,4],[1,3]]` returns `1` (remove `[1,3]`).

</Problem>

### Greedy: earliest end first

Removing as few as possible is the same as **keeping as many as possible**. Sort by **end** time and always keep the interval that finishes first. Finishing early never hurts: it leaves the most room for everything after it.

Walk through the sorted list, remembering the end of the last interval you kept. If the next one starts before that, it overlaps, so remove it.

<CodeTabs>

```python
def erase_overlap_intervals(intervals: list[list[int]]) -> int:
    intervals.sort(key=lambda x: x[1])  # earliest end first
    removed = 0
    prev_end = float("-inf")
    for start, end in intervals:
        if start >= prev_end:
            prev_end = end    # keep it
        else:
            removed += 1      # overlaps the last kept interval
    return removed
```

```java
public int eraseOverlapIntervals(int[][] intervals) {
    Arrays.sort(intervals, (a, b) -> Integer.compare(a[1], b[1]));  // earliest end first
    int removed = 0;
    long prevEnd = Long.MIN_VALUE;
    for (int[] cur : intervals) {
        if (cur[0] >= prevEnd) prevEnd = cur[1];  // keep it
        else removed++;                           // overlaps the last kept interval
    }
    return removed;
}
```

```cpp
int eraseOverlapIntervals(vector<vector<int>> intervals) {

}
```

function eraseOverlapIntervals(intervals) {
  intervals.sort((a, b) => a[1] - b[1]); // earliest end first
  let removed = 0;
  let prevEnd = -Infinity;

<Callout type="interview">
Clarify whether touching intervals count as overlapping. `[1, 2]` and `[2, 3]` overlap in some problems (a meeting ending at 2 and one starting at 2 may need different rooms) and not in others. The answer decides whether you compare with `<` or `<=`.
</Callout>
