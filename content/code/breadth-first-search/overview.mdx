## The level-by-level template

The key trick for tree BFS is to **record the queue's size at the start of each round**. At that moment the queue holds exactly one full level, so processing that many nodes processes the level, while their children line up behind them as the next level.

<CodeTabs>

```python
from collections import deque

def level_order(root: TreeNode | None) -> list[list[int]]:
    if root is None:
        return []
    result = []
    queue = deque([root])
    while queue:
        level = []
        for _ in range(len(queue)):      # exactly the nodes on this level
            node = queue.popleft()
            level.append(node.val)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        result.append(level)
    return result
```

```java
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;
    Queue<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        List<Integer> level = new ArrayList<>();
        for (int i = queue.size(); i > 0; i--) {  // exactly the nodes on this level
            TreeNode node = queue.poll();
            level.add(node.val);
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        result.add(level);
    }
    return result;
}
```

```cpp
vector<vector<int>> levelOrder(TreeNode* root) {
    vector<vector<int>> result;
    if (!root) return result;
    queue<TreeNode*> q;
    q.push(root);
    while (!q.empty()) {
        vector<int> level;
        for (int i = q.size(); i > 0; i--) {  // exactly the nodes on this level
            TreeNode* node = q.front();
            q.pop();
            level.push_back(node->val);
            if (node->left) q.push(node->left);
            if (node->right) q.push(node->right);
        }
        result.push_back(level);
    }
    return result;
}
```

```javascript
function levelOrder(root) {
  const result = [];
  let level = root ? [root] : [];
  while (level.length > 0) {
    result.push(level.map((node) => node.val));
    const next = [];
    for (const node of level) {
      if (node.left) next.push(node.left);
      if (node.right) next.push(node.right);
    }
    level = next; // the next level replaces the current one
  }
  return result;
}
```

</CodeTabs>

The JavaScript version keeps each level in its own array instead of one shared queue. It's the same algorithm, and it avoids the `O(n)` cost of `Array.shift()`.

## Adapting the template

Almost every tree BFS problem is this template with a different "what do I do with a level?" step:

| Problem | Per-level work |
|---------|----------------|
| [Level Order Sum](/learn/code/breadth-first-search/level-order-sum) | Add up the level's values |
| [Rightmost Node](/learn/code/breadth-first-search/rightmost-node) | Keep the last node of the level |
| [Zigzag Level Order](/learn/code/breadth-first-search/zigzag-level-order) | Reverse every other level |
| [Maximum Width](/learn/code/breadth-first-search/maximum-width) | Compare positions of the first and last node |
| Minimum depth | Stop at the first level that contains a leaf |

## Complexity

Each node enters and leaves the queue once: `O(n)` time. The queue holds at most one level plus part of the next, so space is `O(w)`, where `w` is the tree's maximum width (up to about `n / 2` for a complete tree).

<Callout type="interview">
If the question mentions "level", "row", "depth by depth" or "closest to the root", say "this is a level-order traversal" and write the template. It's one of the most reliable patterns in interviews.
</Callout>
