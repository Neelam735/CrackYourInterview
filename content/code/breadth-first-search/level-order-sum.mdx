<Problem difficulty="Easy" link="https://leetcode.com/problems/maximum-level-sum-of-a-binary-tree/">

Given the `root` of a binary tree, return a list where the `i`th entry is the **sum of the values on level `i`** (the root is level 0).

**Example:** `root = [1, 7, 0, 7, -8, null, null]` returns `[1, 7, -1]`.

</Problem>

## Approach

Use the [level-by-level BFS template](/learn/code/breadth-first-search/overview). For each level, instead of collecting the values in a list, add them up.

The linked LeetCode problem asks a closely related question, "which level has the largest sum?", which you can answer from this list with one more pass.

## Solution

<CodeTabs>

```python
from collections import deque

def level_sums(root: TreeNode | None) -> list[int]:
    if root is None:
        return []
    sums = []
    queue = deque([root])
    while queue:
        total = 0
        for _ in range(len(queue)):
            node = queue.popleft()
            total += node.val
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        sums.append(total)
    return sums
```

```java
public List<Integer> levelSums(TreeNode root) {
    List<Integer> sums = new ArrayList<>();
    if (root == null) return sums;
    Queue<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int total = 0;
        for (int i = queue.size(); i > 0; i--) {
            TreeNode node = queue.poll();
            total += node.val;
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        sums.add(total);
    }
    return sums;
}
```

```cpp
vector<int> levelSums(TreeNode* root) {
    vector<int> sums;
    if (!root) return sums;
    queue<TreeNode*> q;
    q.push(root);
    while (!q.empty()) {
        int total = 0;
        for (int i = q.size(); i > 0; i--) {
            TreeNode* node = q.front();
            q.pop();
            total += node->val;
            if (node->left) q.push(node->left);
            if (node->right) q.push(node->right);
        }
        sums.push_back(total);
    }
    return sums;
}
```

```javascript
function levelSums(root) {
  const sums = [];
  let level = root ? [root] : [];
  while (level.length > 0) {
    sums.push(level.reduce((total, node) => total + node.val, 0));
    const next = [];
    for (const node of level) {
      if (node.left) next.push(node.left);
      if (node.right) next.push(node.right);
    }
    level = next;
  }
  return sums;
}
```

<Callout type="tip">
You can also solve this with DFS by passing the depth down: `sums[depth] += node.val`. Either way works. BFS makes the "per level" structure explicit, which is easier to explain.
</Callout>
