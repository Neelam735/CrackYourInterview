<Problem difficulty="Medium" link="https://leetcode.com/problems/longest-increasing-subsequence/">

Given an integer array `nums`, return the length of the longest **strictly increasing subsequence**. A subsequence keeps the original order but may skip elements.

**Example:** `nums = [10, 9, 2, 5, 3, 7, 101, 18]` returns `4` (for example `2, 3, 7, 101`).

</Problem>

## Approach

A "prefix" state doesn't work well here: knowing the best answer for `nums[0..i]` doesn't tell you whether `nums[i + 1]` can extend it, because you don't know its last value. So define the state by **where the subsequence ends**.

**State.** `dp[i]` = the length of the longest increasing subsequence that **ends at index `i`**.

**Recurrence.** The element before `nums[i]` in that subsequence is some earlier `nums[j]` with `nums[j] < nums[i]`. Take the best of them:

```text nocheck
dp[i] = 1 + max(dp[j] for j < i if nums[j] < nums[i])     (or 1 if there's no such j)
```

**Answer.** The subsequence could end anywhere, so return `max(dp)`.

## Solution

<CodeTabs>

```python
def length_of_lis(nums: list[int]) -> int:
    dp = [1] * len(nums)                   # every element alone has length 1
    for i in range(len(nums)):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)   # extend the subsequence ending at j
    return max(dp)
```

```java
public int lengthOfLIS(int[] nums) {
    int[] dp = new int[nums.length];
    Arrays.fill(dp, 1);  // every element alone has length 1
    int best = 1;
    for (int i = 0; i < nums.length; i++) {
        for (int j = 0; j < i; j++) {
            if (nums[j] < nums[i]) dp[i] = Math.max(dp[i], dp[j] + 1);  // extend the one ending at j
        }
        best = Math.max(best, dp[i]);
    }
    return best;
}
```

```cpp
int lengthOfLIS(const vector<int>& nums) {
    vector<int> dp(nums.size(), 1);  // every element alone has length 1
    for (size_t i = 0; i < nums.size(); i++)
        for (size_t j = 0; j < i; j++)
            if (nums[j] < nums[i]) dp[i] = max(dp[i], dp[j] + 1);  // extend the one ending at j
    return *max_element(dp.begin(), dp.end());
}
```

```javascript
function lengthOfLIS(nums) {
  const dp = new Array(nums.length).fill(1); // every element alone has length 1
  for (let i = 0; i < nums.length; i++)
    for (let j = 0; j < i; j++)
      if (nums[j] < nums[i]) dp[i] = Math.max(dp[i], dp[j] + 1); // extend the one ending at j
  return Math.max(...dp);
}
```

<Callout type="interview" title="The O(n log n) follow-up">
Keep an array `tails`, where `tails[k]` is the **smallest possible last value** of an increasing subsequence of length `k + 1`. For each number, binary search for the first entry `≥` it and replace that entry (or append if there's none). `tails` stays sorted, and its length is the answer. Interviewers often ask for this after the `O(n²)` version.
</Callout>
