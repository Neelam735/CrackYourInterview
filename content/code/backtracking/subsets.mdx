<Problem difficulty="Medium" link="https://leetcode.com/problems/subsets/">

Given an array `nums` of **unique** integers, return all possible subsets (the power set), in any order. The answer must not contain duplicate subsets.

**Example:** `nums = [1, 2, 3]` returns `[[], [1], [1, 2], [1, 2, 3], [1, 3], [2], [2, 3], [3]]`.

</Problem>

## Approach

Use the "pick the next element" tree from [Solution Space Trees](/learn/code/backtracking/solution-space-trees):

- Every node of the tree is a valid subset, so **record the path at every call**, not only at the leaves.
- To avoid producing `[2, 1]` as well as `[1, 2]`, only choose elements **after** the last one chosen: pass a `start` index and loop from there.

## Solution

<CodeTabs>

```python
def subsets(nums: list[int]) -> list[list[int]]:
    result, path = [], []

    def backtrack(start):
        result.append(path[:])          # every path is a subset
        for i in range(start, len(nums)):
            path.append(nums[i])        # choose
            backtrack(i + 1)            # explore
            path.pop()                  # un-choose

    backtrack(0)
    return result
```

```java
public List<List<Integer>> subsets(int[] nums) {
    List<List<Integer>> result = new ArrayList<>();
    backtrack(nums, 0, new ArrayList<>(), result);
    return result;
}

private void backtrack(int[] nums, int start, List<Integer> path, List<List<Integer>> result) {
    result.add(new ArrayList<>(path));         // every path is a subset
    for (int i = start; i < nums.length; i++) {
        path.add(nums[i]);                     // choose
        backtrack(nums, i + 1, path, result);  // explore
        path.remove(path.size() - 1);          // un-choose
    }
}
```

```cpp
void backtrack(const vector<int>& nums, int start, vector<int>& path, vector<vector<int>>& result) {
    result.push_back(path);  // every path is a subset
    for (int i = start; i < (int)nums.size(); i++) {
        path.push_back(nums[i]);               // choose
        backtrack(nums, i + 1, path, result);  // explore
        path.pop_back();                       // un-choose
    }
}

vector<vector<int>> subsets(const vector<int>& nums) {
    vector<vector<int>> result;
    vector<int> path;
    backtrack(nums, 0, path, result);
    return result;
}
```

```javascript
function subsets(nums) {
  const result = [];
  const path = [];
  const backtrack = (start) => {
    result.push([...path]); // every path is a subset
    for (let i = start; i < nums.length; i++) {
      path.push(nums[i]);   // choose
      backtrack(i + 1);     // explore
      path.pop();           // un-choose
    }
  };
  backtrack(0);
  return result;
}
```

<Callout type="tip" title="Bitmask alternative">
Each subset of `n` elements matches an `n`-bit number: bit `i` says whether `nums[i]` is included. Looping `mask` from `0` to `2ⁿ - 1` and collecting the set bits lists every subset without recursion.
</Callout>
