<Problem difficulty="Medium" link="https://leetcode.com/problems/path-sum-ii/">

Given the `root` of a binary tree and an integer `targetSum`, return **all** root-to-leaf paths whose values add up to `targetSum`. Each path is a list of node values.

**Example:** `root = [5, 4, 8, 11, null, 13, 4, 7, 2, null, null, 5, 1]`, `targetSum = 22` returns `[[5, 4, 11, 2], [5, 8, 4, 5]]`.

</Problem>

## Approach

This extends [Path Sum](/learn/code/depth-first-search/path-sum): instead of a yes/no answer, you collect the actual paths. Pass two things down:

- `remaining`: how much of the target is still needed.
- `path`: the values from the root to the current node.

At a leaf where `remaining` hits zero, **copy** the path into the results.

Use a **single shared list** for `path`: append the node's value before going deeper, and pop it after both children are done. This choose / explore / undo shape is [backtracking](/learn/code/backtracking/overview), and it avoids copying the path at every node.

## Solution

<CodeTabs>

```python
def path_sum(root: TreeNode | None, target_sum: int) -> list[list[int]]:
    result, path = [], []

    def dfs(node, remaining):
        if node is None:
            return
        path.append(node.val)
        remaining -= node.val
        if node.left is None and node.right is None and remaining == 0:
            result.append(path[:])        # copy: path keeps changing
        dfs(node.left, remaining)
        dfs(node.right, remaining)
        path.pop()                        # undo before returning to the parent

    dfs(root, target_sum)
    return result
```

```java
public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
    List<List<Integer>> result = new ArrayList<>();
    dfs(root, targetSum, new ArrayList<>(), result);
    return result;
}

private void dfs(TreeNode node, int remaining, List<Integer> path, List<List<Integer>> result) {
    if (node == null) return;
    path.add(node.val);
    remaining -= node.val;
    if (node.left == null && node.right == null && remaining == 0) {
        result.add(new ArrayList<>(path));  // copy: path keeps changing
    }
    dfs(node.left, remaining, path, result);
    dfs(node.right, remaining, path, result);
    path.remove(path.size() - 1);           // undo before returning to the parent
}
```

```cpp
void dfs(TreeNode* node, int remaining, vector<int>& path, vector<vector<int>>& result) {
    if (!node) return;
    path.push_back(node->val);
    remaining -= node->val;
    if (!node->left && !node->right && remaining == 0) result.push_back(path);  // copy
    dfs(node->left, remaining, path, result);
    dfs(node->right, remaining, path, result);
    path.pop_back();  // undo before returning to the parent
}

vector<vector<int>> pathSum(TreeNode* root, int targetSum) {
    vector<vector<int>> result;
    vector<int> path;
    dfs(root, targetSum, path, result);
    return result;
}
```

```javascript
function pathSum(root, targetSum) {
  const result = [];
  const path = [];
  const dfs = (node, remaining) => {
    if (node === null) return;
    path.push(node.val);
    remaining -= node.val;
    if (!node.left && !node.right && remaining === 0) result.push([...path]); // copy
    dfs(node.left, remaining);
    dfs(node.right, remaining);
    path.pop(); // undo before returning to the parent
  };
  dfs(root, targetSum);
  return result;
}
```

<Complexity time="O(n²) worst case (copying paths)" space="O(h) besides the output" />

<Callout type="warning">
Don't stop early when `remaining` becomes negative. Node values can be negative, so a path that's "over" the target can come back down.
</Callout>
